PayOff is an UI wrapper around the existing NPCI's UPI *99# USSD feature. It doesn't require any active internet connection for a payment to be made, as it solely relies on the cellular signal of the device. It offers features like:

* Sending payments to QR codes and Phone Numbers
* Checking balance of the current bank account
* Saving history of any transactions made using this app
* Paying using Biometrics

  ...and many more not mentioned or yet to be developed!

This project is completely open-source and will remain open-sourced until there's a feature which specifically requires for the code to be hidden.

KEEP IN MIND that this app hasn't been completely developed, so it hasn't been tested on every single device and is NOT guarented to work on your specific device. All of the tested devices include:

1. NothingOS (Nothing, CMF)
2. OneUI (Samsung)
3. Funtouch OS (Vivo)

The app is currently found to be NOT working in:

1. OxygenOS (OnePlus)
2. Google Pixel

Proceed with caution. And here are the steps to install this app for testing:

1. Download the APK from the latest release [found here](https://github.com/gamesbnch1012/PayOff/releases) and don't install it yet.
2. Open Play Store -> Tap on your profile on top-right corner -> Tap on Play Protect -> Tap on the settings icon on top-right -> Turn off 'Scan apps with Play Protect' -> Tap on 'Pause'
3. Install the APK you downloaded. If asked, allow permission to install APKs from external sources. Open the app once and close it when asked to enable some options.
4. Open the app's info page by pressing and holding the app -> Tap app info -> Tap on the three dots on top-right corner -> Tap on 'Allow restricted settings'
5. Open the app normally. Give the necessary permissions, if it doesn't work properly, sometimes closing the app from recents and opening again will allow the app to gain all the permissions.

Don't forget to click on 'Report Issue' in the Settings menu of the app if you face any issue! None of your personal information is taken. Trust me :P
